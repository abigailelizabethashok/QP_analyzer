# Description
AI Question Paper Analyzer is a web-based application that helps teachers analyze question papers efficiently. It evaluates syllabus coverage, marks distribution, question difficulty, repeated questions, and Bloom's Taxonomy levels, providing useful insights to create more balanced and effective assessments.

# Problem Statement
Teachers often have to manually review question papers to ensure proper syllabus coverage, balanced marks distribution, appropriate difficulty levels, minimal repetition, and a suitable distribution of Bloom's Taxonomy levels. This process is time-consuming and can lead to inconsistencies.

# Objective

To develop an easy-to-use AI-powered web application that automates question paper analysis and provides teachers with quick insights and recommendations for creating well-balanced and effective question papers.
